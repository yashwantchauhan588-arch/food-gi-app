# 🥗 Food GI Scanner - AI Powered Mobile App

Food GI Scanner ek Progressive Web App (PWA) hai jo camera se khane ki photo dekhkar Google Gemini AI ki madad se uska:
- **Glycemic Index (GI)** [0 to 100]
- **Glycemic Load (GL)**
- **Carbohydrates, Sugar, Fiber, Calories, Protein**
- **Diabetic Safety Recommendations**
turant nikal kar deta hai.

---

## 🚀 App Ko Run Kaise Karein

### Step 1: App Start Karein
Aapke folder me `run_app.bat` file hai:
- Bas **`run_app.bat`** par double click karein.
- Ek terminal window khulegi aur browser me app automatically open ho jayegi.

### Step 2: Gemini API Key Daalein
- App khulte hi Settings (⚙️ icon) par click karein.
- Apni Google Gemini API Key paste karke **Save Settings** par click karein.
- Key aapke browser me securely save ho jayegi.

### Step 3: Apne Android Phone Par Install Karein
1. Make sure aapka Phone aur Laptop **same Wi-Fi** se connected hain.
2. Phone ke Chrome browser me yeh address open karein:
   `http://192.168.1.63:5000`
   *(Ya app ke andar bane mobile icon 📱 par click karke QR code scan karein)*.
3. Phone ke Chrome me top right 3 dots (⋮) par click karein aur **"Install app"** ya **"Add to Home screen"** par tap karein.
4. App aapke phone ke home screen par **asli Android App** ki tarah install ho jayegi!

---

## 📸 Food Test Kaise Karein
1. **Camera 📸** button dabakar kisi bhi food/thali ki photo kheechein.
2. **Calculate GI** button dabayein.
3. 2-3 seconds me food ka poora Glycemic Report aapki screen par hoga!
